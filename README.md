# 长歌 · 云端接口聚合

苹果毛玻璃风格的开源 API 导航页，聚合国内外可用接口，一键复制地址、直达接口文档。

## 特性

- 苹果风毛玻璃 + 樱花花瓣粒子背景（重构自小白菜云端模板）
- 国内接口 **149** 个 + 国外公开免费接口 **39** 个，共 **188** 个
- 实时搜索、分类筛选、一键复制、新标签查看返回
- 自包含单文件，零依赖，直接部署到 GitHub Pages / Vercel / Cloudflare Pages

## 使用

### 部署到 GitHub Pages

1. Fork 本仓库
2. 仓库 **Settings → Pages**，选择分支 `main` 根目录
3. 稍等片刻即可通过 `https://<你的用户名>.github.io/<仓库名>/` 访问

### 部署到自己的服务器

将 `index.html` 放在站点根目录，与 `api/`、`doc/` 目录同级即可访问国内接口。

## 目录说明

| 目录 | 说明 |
| --- | --- |
| `index.html` | 自包含单文件页面 |
| `api/` | 国内接口端点（PHP） |
| `doc/` | 国内接口文档页（PHP） |

国外 API 均为公开免费接口，不需要后端，点击「接口文档」即可在新标签页查看实时 JSON 返回。
